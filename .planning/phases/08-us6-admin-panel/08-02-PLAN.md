Create `admin/app/actions/programs.ts` with `'use server'` directive:

1. Import `createServiceClient` from `@/lib/supabase/service`
2. Import `revalidatePath` from `next/cache`, `redirect` from `next/navigation`
3. Import `z` from `zod`

4. Define Zod schemas:
   ```typescript
   const ProgramSchema = z.object({
     title: z.string().min(1, 'Title is required').max(100),
     description: z.string().optional().default(''),
     difficulty: z.enum(['beginner', 'intermediate', 'advanced']),
     duration_weeks: z.coerce.number().int().positive().max(52),
     thumbnail_url: z.string().optional(),
   })
   ```

5. Export `createProgram(prevState: unknown, formData: FormData)`:
   - Parse with ProgramSchema.safeParse(Object.fromEntries(formData))
   - If invalid, return `{ errors: result.error.flatten().fieldErrors }`
   - Insert into `programs` table using service client
   - Call `revalidatePath('/programs')`
   - Call `redirect(`/programs/${data.id}`)`

6. Export `updateProgram(programId: string, prevState: unknown, formData: FormData)`:
   - Same validation as create
   - Update `programs` where id = programId, include `updated_at: new Date().toISOString()`
   - `revalidatePath('/programs')` and `revalidatePath(`/programs/${programId}`)`
   - Return `{ success: true }`

7. Export `deleteProgram(programId: string)`:
   - Delete from `programs` where id = programId (cascade handles children)
   - `revalidatePath('/programs')`
   - `redirect('/programs')`

8. Export `publishProgram(programId: string)`:
   - Update `programs` set `published = true, published_at = new Date().toISOString()`
   - `revalidatePath('/programs')` and `revalidatePath(`/programs/${programId}`)`

9. Export `unpublishProgram(programId: string)`:
   - Update `programs` set `published = false, published_at = null`
   - `revalidatePath('/programs')` and `revalidatePath(`/programs/${programId}`)`

10. Export `uploadThumbnail(programId: string, formData: FormData)`:
    - Extract file from formData: `formData.get('file') as File`
    - Validate file exists and is an image (check type starts with 'image/')
    - Generate storage path: `thumbnails/${programId}/${file.name}`
    - Upload using service client: `supabase.storage.from('program-assets').upload(path, file, { upsert: true })`
    - Update programs table: `supabase.from('programs').update({ thumbnail_url: path, updated_at: new Date().toISOString() }).eq('id', programId)`
    - `revalidatePath(`/programs/${programId}`)`
    - Return `{ success: true, path }`
  </action>
