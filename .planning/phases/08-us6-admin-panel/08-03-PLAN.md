   - Parse formData, return errors if invalid

     ```
     { coach_reply: reply, replied_at: new Date().toISOString(), notification_sent: false }
     ```
   - Select `student_id` from the updated row
   - Fire FCM push via fetch to Supabase Edge Function:
     ```typescript
     await fetch(
       `${process.env.NEXT_PUBLIC_SUPABASE_URL}/functions/v1/send-fcm`,
       {
         method: 'POST',
         headers: {
           'Content-Type': 'application/json',
           Authorization: `Bearer ${process.env.SUPABASE_SERVICE_ROLE_KEY}`,
         },
         body: JSON.stringify({ threadId, studentId: thread.student_id }),
       }
     )
     ```
   - Call `revalidatePath('/feedback')` and `revalidatePath(`/feedback/${threadId}`)`
   - Return `{ success: true }`

2. Create `supabase/functions/send-fcm/index.ts`:
   - Add `import "@supabase/functions-js/edge-runtime.d.ts"` at top
   - Import `createClient` from `https://esm.sh/@supabase/supabase-js@2`
   - Implement `Deno.serve(async (req) => { ... })`:
     a. Return 405 if not POST
     b. Parse JSON body: `{ threadId, studentId }`
     c. Create Supabase client with `Deno.env.get('SUPABASE_URL')` and `Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')`
     d. Fetch student's fcm_token: `supabase.from('students').select('fcm_token').eq('id', studentId).single()`
     e. If no fcm_token, return `{ sent: false, reason: 'no_token' }`
     f. Implement `getFcmAccessToken()` helper:
        - Read `FIREBASE_SERVICE_ACCOUNT_JSON` from env (stored in Supabase Vault)
        - Parse service account JSON to get `client_email` and `private_key`
        - Create a JWT with:
          - Header: `{ alg: 'RS256', typ: 'JWT' }`
          - Payload: `{ iss: client_email, sub: client_email, aud: 'https://oauth2.googleapis.com/token', iat: now, exp: now + 3600, scope: 'https://www.googleapis.com/auth/firebase.messaging' }`
        - Sign with private_key using `crypto.subtle.importKey` (PKCS8) and `crypto.subtle.sign` (RSASSA-PKCS1-v1_5)
        - Exchange JWT for access token: POST to `https://oauth2.googleapis.com/token` with `grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer&assertion=<jwt>`
        - Return the access_token from response
     g. Call FCM v1 API:
        ```
        POST https://fcm.googleapis.com/v1/projects/${Deno.env.get('FIREBASE_PROJECT_ID')}/messages:send
        Authorization: Bearer ${accessToken}
        Body: {
          message: {
            token: student.fcm_token,
            notification: { title: 'Coach replied', body: 'Your coach has replied to your feedback.' },
            data: { type: 'coach_reply', threadId }
          }
        }
        ```
     h. If FCM response ok, update `feedback_threads` set `notification_sent = true` where id = threadId
     i. Return `{ sent: fcmResponse.ok, status: fcmResponse.status }`
