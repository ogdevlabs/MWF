## Decisions Made

- StorageGuard production path is fail-open (returns true without actual space check) — `dart:io` `FileStat` doesn't expose free disk space, so a real check would require a platform plugin; Phase 9 can add one if needed
- `StorageGuard.hasEnoughSpace()` check placed before manifest upsert — returns early without side effects if space is insufficient
- `resumeQueue()` only processes entries with `downloadStatus == 'pending'` (via `getPendingDownloads()` DAO method which filters on that status)
