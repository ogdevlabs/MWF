**Offline-first CQRS FeedbackRepository with Drift local write + SyncQueue enqueue, sentinel session ID, photo upload stub, and Riverpod providers matching MetricRepository pattern**

## Accomplishments

- FeedbackRepository implements CQRS pattern: `submitFeedback` writes to Drift locally first, then enqueues SyncQueue for remote replay — identical pattern to MetricRepository
- `kGeneralSessionId = '00000000-0000-0000-0000-000000000000'` sentinel constant defined for free-form DM messages not tied to a session
- Online/offline paths handled by `isOnline` param: status='sent' when online, status='pending' when offline; `localPhotoPath` stored for deferred photo upload
- Riverpod providers generated cleanly: `feedbackRepositoryProvider` (keepAlive), `feedbackThreadProvider` (stream), `coachRepliesProvider` (stream)
- 7 unit tests pass covering all behaviors (TDD red/green)

- `FeedbackStatus` enum names map to strings via `.name` — consistent with Drift `text()` column storage.
