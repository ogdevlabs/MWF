## Decisions Made

- Drift schemaVersion 3 uses `addColumn` (non-destructive) for both new columns — safe for existing users upgrading
- `status` defaults to `'sent'` so existing rows don't break; `localPhotoPath` is nullable for messages without photos
- google-services plugin declared with `apply false` at root level, applied in the app subproject — standard pattern for multi-module Android builds
- feedback-photos bucket is private (`public: false`), RLS grants students access only to their own folder (uid as first path segment), coach gets full read access
