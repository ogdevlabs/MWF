   - The ScaffoldWithNavBar is a wrapper widget

   HOWEVER — this is a significant router restructure. Given Phase 9 (Polish) will likely handle navigation refinements, and the existing router is flat, the MINIMAL viable approach for Phase 7 is:

   ```dart
       StatefulShellBranch(routes: [GoRoute(path: '/programs', ...)]),
       StatefulShellBranch(routes: [GoRoute(path: '/progress', ...)]),

     ],
   )
   ```
